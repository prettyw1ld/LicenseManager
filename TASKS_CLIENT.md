# Задачи для клиента (@balecore2018)

Клиент делается в папке `LicenseClient/` в этом же репозитории (в своей ветке, например `client`,
потом pull request в `main`). Протокол описан в [README.md](README.md#протокол-обмена).
Технология на выбор: Console или WPF, .NET 8, `TcpClient`.

Важно: по условиям работы каждый участник должен фиксировать свои изменения в репозитории,
иначе работа ему не засчитывается. Коммить по мере выполнения пунктов ниже.

## 1. Проект и настройки
- [ ] Создать проект `LicenseClient` (Console или WPF) и добавить его в `LicenseManager.slnx`.
- [ ] При первом запуске запрашивать у пользователя IP-адрес и порт сервера (по умолчанию `127.0.0.1:5050`).
- [ ] Запрашивать логин и пароль (тестовые: `damir` / `12345`, `user1` / `12345`).

## 2. Подключение и получение кода
- [ ] Подключиться по TCP, прочитать `HELLO`.
- [ ] Отправить `AUTH`, получить `CODE` (или `ERROR`).
- [ ] Сразу после каждого `CODE` отправить `CONFIRM` с этим кодом.
- [ ] Отдельный поток/таск, который читает строки от сервера и разбирает JSON по полю `type`.

## 3. Отображение информации
- [ ] Показывать: дату и время подключения, продолжительность подключения (обновляется каждую секунду),
      IP-адрес и порт клиента, уникальный код, сколько осталось до отключения.
      Данные берутся из `HELLO` / `CODE` / `STATUS`.

## 4. Периодические запросы
- [ ] Каждые ~5 секунд отправлять `CHECK` (проверка «не заблокирован ли»). Если `blocked = true` — сообщить пользователю.
- [ ] По таймеру (например, раз в минуту) или по кнопке отправлять `RENEW` и подтверждать новый код.

## 5. Обработка ошибок и отключений
- [ ] `ERROR`: показать `message` (`AUTH_FAILED` — дать ввести пароль ещё раз, `NO_SLOTS`, `BLACKLISTED`, `ALREADY_CONNECTED`).
- [ ] `DISCONNECT`:
  - `EXPIRED` / `CONFIRM_TIMEOUT` — автоматически переподключиться и получить новый код;
  - `KICKED`, `BLACKLISTED`, `SERVER_SHUTDOWN`, `REJECTED` — показать сообщение и не переподключаться.
- [ ] Обработать обрыв соединения и недоступность сервера (без падения программы).
- [ ] При выходе отправлять `BYE`.

## 6. Совместная отладка
- [ ] Проверить вместе с сервером сценарии: 6-й клиент при 5 лицензиях, клиент из чёрного списка (`banned`),
      `kick` и `ban` с сервера, истечение времени, неверный пароль.
- [ ] Сделать скриншоты для отчёта.
